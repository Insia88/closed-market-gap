# 휴장 구간 갭 전략

Closed-Market Gap Strategy · KOSPI200 선물 × CME 지수 선물

**한국 선물시장이 닫혀 있는 동안 CME 지수 선물이 먼저 반영한 정보로 KOSPI200 선물의 정규장 시가를 예측하고, 실제 시가가 예측에서 크게 벗어난 날만 개장 직후 거래한다.**

지금은 **사전 등록(pre-registration) 단계**다. 가설과 판정 기준은 데이터를 보기 전에 먼저 적어 두었고, 코드와 검증 결과는 아직 없다. 기준을 바꾸면 날짜와 이유를 아래 변경 기록에 남긴다.

## 한국 시장이 닫힌 시간은 세 종류다

KRX 야간 거래가 생긴 뒤에도 **정규장 시가 직전의 공백은 사라지지 않았다.** 평일 새벽 공백은 짧아졌지만, 주말과 국내 연휴 공백은 그대로 남아 있다.

| 구간 | 한국 시간 | 길이 | 그동안 정보가 먼저 반영되는 곳 |
|---|---|---|---|
| 평일 새벽 | 06:00 야간 거래 종료 ~ 08:45 정규장 개장 | 2시간 45분 | CME 지수 선물 |
| 주말 | 토 06:00 ~ 월 08:45 | 50시간 45분 | 월 07:00부터 CME (미국 서머타임이 끝나면 08:00부터) |
| 국내 연휴 | 연휴 앞 마지막 거래 종료 ~ 연휴 뒤 첫 정규장 | 연휴마다 다름 | 열려 있는 해외 시장 전체 |

주말에는 CME도 쉰다. CME 지수 선물은 한국 시간 월요일 오전 7시(미국 서머타임이 끝나면 8시)에 다시 열리므로, **주말 동안 쌓인 정보는 이때부터 CME 가격에 먼저 나타난다.**

## 갭에서 해외 정보로 설명되지 않는 몫만 거래한다

갭은 직전 거래 마감가와 정규장 시가의 차이다. 같은 구간에 CME 지수 선물(E-mini S&P 500 등)이 움직인 폭에 과거 데이터로 추정한 민감도를 곱하면, 갭 가운데 해외 정보로 설명되는 몫이 나온다.

**나머지가 '설명되지 않는 갭'이고, 이 값이 앞 기간 데이터로 정한 기준보다 큰 날만 거래 후보가 된다.** 설명되는 몫은 해외 정보가 시가에 제대로 반영된 부분으로 보고 거래하지 않는다.

## 검증할 가설은 두 개다

1. **설명되지 않는 갭은 개장 후 1시간 안에 우연으로 보기 어려운 방향성을 보인다.** 그 방향이 되돌림인지 추세 지속인지는 앞 기간 데이터로 정한다.
2. **휴장이 길수록, 그리고 야간 거래가 한산할수록 설명되지 않는 갭이 커진다.**

보조 가설로는 주말에도 쉬지 않는 가상자산 시장의 움직임이 월요일 갭을 추가로 설명하는지 확인한다.

## 판정 기준은 데이터를 보기 전에 정해 둔다

- **표본 분할:** 데이터를 시간 순서대로 앞 기간과 뒤 기간으로 나눈다. 민감도, 거래 기준, 방향은 앞 기간에서만 정하고 뒤 기간에는 그대로 적용한다.
- **방향성 검정:** 개장 후 1시간의 방향이 우연(적중률 50%)과 다른지를 유의수준 5%로 검정한다.
- **성과 지표:** 비용을 뺀 거래당 기대값, 최대 낙폭, 구간 유형(평일 새벽·주말·연휴)별 안정성을 본다. 누적 수익률 하나로 판단하지 않는다.
- **비교 기준:** 무조건 되돌림, 무조건 추종이라는 두 가지 단순 전략과 비교한다.
- **통과 조건:** 뒤 기간에서 비용을 뺀 거래당 기대값이 0보다 크고, 두 비교 기준보다 나아야 한다.

가설이 틀려도 결과는 지우지 않는다. **어느 구간에서 왜 틀렸는지가 이 프로젝트의 두 번째 산출물이다.**

## 데이터는 NH선물 REST API로 모으고 주문까지 낸다

| 쓰임 | 경로 | 대상 |
|---|---|---|
| 백테스트 데이터 | REST API 분봉 조회 | KOSPI200 선물, CME 지수 선물 |
| 실시간 신호 | WebSocket 시세 | 휴장 구간 해외 선물, 개장 직후 국내 선물 |
| 주문 | REST API 모의투자 주문 | 미니 KOSPI200 선물 |

과거 데이터 제공 범위는 1주차에 먼저 확인하고, 모자라면 공개 데이터로 보완한다. **모든 API 호출은 로그로 남기고**, 개발 중에 발견한 API 오류와 문서 개선점은 `docs/api-issues.md`에 따로 모은다.

## 주문은 미니 선물 1계약과 킬 스위치로 묶어 둔다

진입은 시가가 확정된 직후다. 정규장 시가는 8시 30분부터 15분 동안의 단일가 매매로 정해지기 때문이다. 주식시장이 열리기 전인 8시 45분부터 9시까지는 선물만 거래되는 구간이라 따로 분석한다.

거래는 **미니 KOSPI200 선물 1계약**으로 한다. 거래승수가 5만 원으로 KOSPI200 선물(25만 원)의 5분의 1이라 손실 한도를 잘게 맞출 수 있다. 여기에 손절선, 시간 청산, 일일 손실 한도를 둔다.

**킬 스위치는 시세 연결이 끊기거나 체결 내역이 계좌 조회와 어긋나면 작동한다.** 새 주문을 멈추고, 미체결 주문 취소와 보유 계약 정리를 먼저 한다.

## 8주 동안 네 단계로 진행한다

일정은 NH선물 REST API Pioneer 1기 운영 일정을 따른다.

| 주차 | 할 일 | 남길 것 |
|---|---|---|
| 1~2주 | API 연결, 데이터 구축 | 수집 코드, 데이터 설명서 |
| 3~4주 | 가설 검증 | 중간행사 발표 (11월 13일) |
| 5~6주 | 실시간 신호, 모의투자 주문 | 모의투자 로그 |
| 7~8주 | 기간 분할 검증, 실패 사례 분석 | 최종발표 (12월 11일) |

## 표본이 짧다는 한계는 검증 방식으로 메운다

- **KRX 야간 거래는 2025년 6월에 시작돼 표본 기간이 짧다.** 그래서 변수를 적게 두고, 사전 등록과 기간 분할 검증으로 과최적화를 막는다.
- **11월 1일 미국 서머타임이 끝나면 월요일 개장 전 CME 거래 시간이 1시간 45분에서 45분으로 줄어든다.** 해외 선물이 정보를 소화할 시간이 짧아질 때 갭이 달라지는지 따로 비교한다.
- **미니 선물은 호가가 얇을 수 있다.** 신호는 KOSPI200 선물 가격으로 만들고, 미니 선물의 호가 간격은 비용 가정에 넣는다.
